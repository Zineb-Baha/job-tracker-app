# Hire – Job Tracking Platform

A full-stack job tracking platform that helps candidates manage their job search and job applications.

The project is being developed with a Spring Boot backend, Angular frontend, and PostgreSQL database.

---

## 📌 Project Status

🚧 **Currently under development**

The authentication module is currently implemented, including user registration, login, password encryption, and JWT-based authentication.

More features will be added progressively.

---
